1 O que é o SGP e por que você usa ele

O SGP registra o tempo que você dedica a cada atividade de uma esteira (OS / veículo). Com esses apontamentos o gestor enxerga o andamento real do serviço sem precisar perguntar a ninguém.

✓ Seu papel é simples: quando terminar um bloco de trabalho, registre quanto tempo você dedicou. O restante acontece automaticamente.

2 Primeiro acesso

  1. Abra o endereço do SGP no navegador (fornecido pelo gestor ou TI).
  2. Digite seu e-mail e sua senha e clique em Entrar.
  3. Se for o primeiro login, o sistema pedirá para você criar uma nova senha — siga as instruções na tela e guarde bem.
⚠ Esqueceu a senha? Peça ao gestor para fazer o reset administrativo.

4 Fazer um Apontamento

Caminho: Minhas Atividades → clique na atividade /app/apontamento/:id

  1. Minutos trabalhados — informe quantos minutos você dedicou nesta sessão (ex.: 90).
  2. Quantidade executada — quantas unidades você processou (ex.: 3 capas costuradas). Deixe 1 se a atividade não tem contagem de unidades.
  3. Data de realização — preenchida automaticamente com hoje; altere se o trabalho foi feito em outro dia.
  4. Observação (opcional) — anote qualquer ocorrência relevante.
  5. Justificativa (aparece quando necessário) — se o tempo excede o previsto ou há outra condição especial, selecione a categoria mais adequada e, se necessário, descreva em texto livre.
  6. Clique em Salvar apontamento.
✓ Uma mensagem verde confirma o registro. Você pode fazer múltiplos apontamentos na mesma atividade ao longo dos dias — não precisa apontar tudo de uma vez.

5 Minha Fila

Caminho: menu lateral → Minha Fila /app/minha-fila

Exibe suas atividades organizadas por data de trabalho, com navegação de dia anterior / dia seguinte.

  • Use esta tela para ver o que está previsto para hoje ou para uma data específica.
  • Clique no botão de apontamento rápido (ícone de relógio) em qualquer atividade para abrir o drawer lateral sem sair da fila.
  • Atividades bloqueadas por sequência aparecem com indicador de aviso — você não pode apontar até que a atividade anterior esteja concluída.

7 SGP+ Produção — Tablet / Totem (Kiosk)

Caminho: endereço especial do Kiosk fornecido pelo gestor /app/kiosk

O tablet fixo na fábrica roda o Modo Kiosk — interface touch-first projetada para ser usada sem teclado.

Fluxo no Kiosk

Grade de colaboradores → Toque no seu avatar ↓ Tela de PIN → Digite seu PIN (4+ dígitos) ↓ Cards de atividades → Toque na atividade que quer apontar ↓ Formulário → Deslize o slider de progresso, ajuste o tempo, toque em Salvar ↓ Volta para a grade (outros colaboradores podem usar)

Primeiro login — troca obrigatória de PIN

  1. Digite o PIN temporário fornecido pelo gestor.
  2. O sistema leva para a tela Criar novo PIN.
  3. Digite um PIN de sua escolha (mínimo 4 dígitos) e confirme.
  4. Pronto — use o novo PIN nas próximas sessões.
⚠ PIN bloqueado? Tentativas incorretas múltiplas bloqueiam o acesso. Peça ao gestor para desbloquear e resetar o PIN no painel de administração de colaboradores.

Card de atividade no Kiosk

ElementoO que fazer
Anel de progressoMostra o % já concluído na atividade
Slider (0 – 100%)Arraste para indicar o progresso atual da sessão

Bloqueio de sequência

Se uma atividade depende de outra que ainda não foi concluída, ela aparece com o aviso "Aguardando atividades anteriores". Você ainda pode apontar, mas precisará selecionar uma justificativa para execução fora de sequência.

8 SGP+ Produção — Interface Web (navegador)

Caminho: endereço especial de produção fornecido pelo gestor /app/producao

Funciona de forma similar ao Kiosk, mas acessível no navegador de qualquer computador.

  1. Acesse /app/producao.
  2. Selecione seu nome na lista de colaboradores (campo de busca disponível).
  3. Digite seu PIN.
  4. Você entra na sua fila de atividades de produção.
  5. Clique no botão de apontamento em qualquer atividade.
  6. Preencha o formulário e clique em Salvar.
ℹ O filtro no topo da fila permite ver: Todas, Pendentes ou Concluídas.

9 Dúvidas frequentes

Esqueci de apontar ontem — o que faço?

Na tela de apontamento, altere o campo Data de realização para o dia correto antes de salvar.

Apontei o tempo errado — posso corrigir?

Fale com o gestor. Gestores com permissão especial podem editar ou remover apontamentos.

A atividade não aparece em Minhas Atividades

Você ainda não foi designado(a) para ela. Peça ao gestor de esteira para verificar a designação.

O Kiosk não aceita meu PIN

Confirme se não há letras ou espaços — o PIN é só numérico. Se o problema persistir, o gestor pode resetar o PIN no painel administrativo.

Minha conta foi bloqueada por tentativas

Fale com o gestor para desbloquear via painel de administração de colaboradores.
