# Playbook: feature-development

## Objetivo

Criar ou ajustar funcionalidade no SGP+ Web com escopo controlado.

## Fluxo

1. Entender a demanda em uma frase.
2. Mapear contexto real.
3. Avaliar impacto.
4. Escrever spec com critérios de aceite.
5. Implementar apenas o necessário.
6. Testar e revisar.
7. Entregar relatório.

## Quando usar

- Mudança com regra de negócio.
- Mudança com backend + frontend.
- Mudança com banco/permissão.
- Mudança com impacto em produção/kiosk/planejamento/apontamento.

## Quando não usar

- Ajuste textual simples.
- CSS isolado.
- Troca de label sem comportamento.
