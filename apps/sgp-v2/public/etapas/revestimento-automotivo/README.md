# Ilustrações do processo de revestimento automotivo

Pacote de 20 SVGs pesquisados e selecionados para corresponder às 20 etapas do documento fornecido pelo usuário, *Fluxo do Processo de Operação.docx*, página 1.

## Uso

- Imagens em `public/assets/revestimento-automotivo/`.
- Veja `manifesto.json` para mapear a etapa ao arquivo SVG. Um exemplo de URL do Vite é `/assets/revestimento-automotivo/16-volante.svg`.
- **Os desenhos vetoriais são ícones simbólicos, não reproduções fotorrealistas das peças.** Alguns ícones são aproximações (especialmente teto, cintos, ombreira, tampão).
- A interface visível ao usuário deve escrever **Etapa**, não `STEP`.
- O aplicativo ainda NÃO foi alterado. Esta é apenas a branch de recursos gráficos, para integração posterior pelo Claude em branch própria e isolada. A V1 não pode ser alterada; conferir a pasta V2 na implementação.
- Não alterar backend, status, IDs, fluxo operacional, banco, migrações, permissões ou deploy para a tarefa de imagens.
